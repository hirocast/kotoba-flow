# Kotoba Flow（コトバフロー）

「英語→日本語の4択」からスタートし、くり返すうちに自然と「日本語→英語のタイピング」まで解けるようになる英単語学習ゲームです。

## 5段階ステップアップ
1. **Lv.1：英 → 日（4択）** — 音と意味をつかむ
2. **Lv.2：日 → 英（4択）** — 英単語の見た目に慣れる
3. **Lv.3：日 → 英（文字タイル並べ替え）** — 片手でスペルを組み立てる
4. **Lv.4：日 → 英（ヒント付きタイピング）** — 1文字目・文字数ヒントを見て入力
5. **Lv.5：日 → 英（ノーヒント・タイピング）** — 自力でスペルを入力してマスター！
